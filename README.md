# CCV Converter (web)

Open **https://sunilkalmadi.github.io/ccv-converter/** and choose a Canadian Common CV XML export.
You get a compact PDF and an editable Word file, in two styles: *Classic* (compact,
every field) and *Reviewer* (organized for grant panels and committees).
Everything runs in your browser and the file is never uploaded.

This repository is published automatically. Please don't edit it here.
Based on Karim Ali's [ccv_reduction](https://github.com/karimali3/ccv_reduction).
